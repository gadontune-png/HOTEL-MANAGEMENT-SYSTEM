# HOTEL MANAGEMENT SYSTEM

A modern full-stack hotel management system built to automate hotel operations such as room booking, room allocation, check-in/check-out, housekeeping management, customer notifications, and staff management.

---

# Problem Statement

Many hotels still manage room bookings, check-ins, housekeeping records, and customer notifications manually or using outdated systems. This creates several operational challenges such as:

- Double booking of rooms
- Difficulty tracking room availability
- Slow check-in and check-out processes
- Poor communication between receptionists and housekeeping staff
- Inaccurate room status updates
- Difficulty managing customer payments
- Lack of automated notifications for bookings and cancellations
- Poor customer experience when searching for rooms

Hotels require a modern, centralized, and responsive system that allows both guests and hotel staff to efficiently manage operations in real time.

---

# Solution

The Hotel Management System provides a centralized platform where:

- Guests can search and book rooms online
- Receptionists can manage bookings and room allocations
- Housekeeping staff can update room status records
- Managers can manage employees and monitor hotel operations
- Automated notifications are sent for bookings and cancellations

The system improves efficiency, reduces manual workload, and enhances customer experience.

# Installation Guide

## Clone Repository

```bash
git clone https://github.com/gadontune-png/HOTEL-MANAGEMENT-SYSTEM.git
```

---

## Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

# Running the Project

## Start Backend Server

```bash
cd backend
npm start
```

Backend runs on:

```text
http://localhost:3001
```

---

## Start Frontend

```bash
cd frontend
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```
